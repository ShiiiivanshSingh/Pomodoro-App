<h1 align="center" id="title">FocusBuddy 📔</h1>

A modern, minimalist focus timer application designed to boost your productivity with a beautiful day/night theme. Stay focused, take breaks, and track your progress with your new study buddy! ⏰


<div align="center">

[![FocusBuddy](https://img.shields.io/badge/Meet_Your-FocusBuddy-blue?style=for-the-badge)](https://pomodoro-app-ten-kappa.vercel.app)
</div>



<h1 align="center">Features 🌟</h1>

- **Dynamic Day/Night Theme** - Automatically adjusts based on time of day
- **Beautiful Animations** - Clouds, stars, and smooth transitions
- **Customizable Timers** - Set your preferred work and break durations
- **Session Tracking** - Keep track of completed focus sessions
- **Keyboard Shortcuts** - Quick controls for better productivity
- **Mobile Responsive** - Works seamlessly on all devices
- **Motivational Messages** - Time-based encouragement throughout the day
- **Distraction-free UI** - Clean and focused design


<h1 align="center">How to Use ⚡</h1>

1. Set your preferred work and break durations
2. Click "Start" to begin your focus session
3. Work until the timer ends
4. Take a break when prompted
5. Repeat and stay productive!

## Installation and Setup 🛠️

1. Clone the repository:
```bash
git clone https://github.com/your-username/focus-buddy.git
```

2. Install dependencies:
```bash
cd focus-buddy
npm install
```

3. Start the development server:
```bash
npm start
```
